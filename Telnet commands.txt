To test the server, one can make another instance and install telnet on it and test the SMTP.

$ sudo yum update

$ sudo yum -y install telnet

$ sudo -s

$ telnet DOMAIN_ADDRESS 25	#replace DOMAIN_ADDRESS with your instance address. Mine is ec2-184-72-99-52.compute-1.amazonaws.com for now.
	telnet ec2-54-89-223-99.compute-1.amazonaws.com 25

$ HELO DOMAIN_ADDRESS
	HELO MAIL ec2-54-89-223-99.compute-1.amazonaws.com

$ MAIL FROM:<adam@DOMAINADDRESS>
	MAIL FROM:<adam@ec2-54-89-223-99.compute-1.amazonaws.com>

$ RCPT TO:<reza@DOMAINADDRESS>
	RCPT TO:<reza@ec2-54-89-223-99.compute-1.amazonaws.com>

$DATA		#then you can start the text of the mail
