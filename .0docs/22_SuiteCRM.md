# SuiteCRM Configuration and Initialization

## Overview

SuiteCRM is a core component of the Thusia web platform, providing Customer Relationship Management functionalities. It runs in a Docker container and is orchestrated by Docker Compose.

## Initialization Script

During the EC2 instance startup, as defined in the `user_data` section of the main Terraform file (`main.tf`), a script named `crm_initialize.sh` is executed. This script is crucial for the proper functioning of SuiteCRM, especially for enabling its API endpoints.

The `crm_initialize.sh` script is generated by the Terraform module located at `___ShredModules___/file_gen_crm_initialize_sh`.

### Script Activities

The `crm_initialize.sh` script performs the following actions:

1.  **Sets File Permissions**: It adjusts the ownership and permissions of various directories within the SuiteCRM container to ensure the web server has the necessary access rights.
    ```bash
    chown -R www-data:www-data /var/www/html
    chmod -R 755 /var/www/html
    chmod -R 775 /var/www/html/public/legacy/cache
    chmod -R 775 /var/www/html/public/legacy/custom
    chmod -R 775 /var/www/html/public/legacy/modules
    chmod -R 775 /var/www/html/public/legacy/upload
    ```

2.  **Installs Composer Dependencies**: It runs `composer install` to download and install the required PHP dependencies for SuiteCRM.
    ```bash
    docker exec -w /var/www/html/public/legacy/ crm bash -c 'composer install'
    ```

3.  **Generates OAuth2 Keys**: It generates a private and public key pair for OAuth2 authentication, which is essential for securing the SuiteCRM API.
    ```bash
    docker exec -w /var/www/html/public/legacy/Api/V8/OAuth2/ crm bash -c 'openssl genrsa -out private.key 2048'
    docker exec -w /var/www/html/public/legacy/Api/V8/OAuth2/ crm bash -c 'openssl rsa -in private.key -pubout -out public.key'
    ```

4.  **Sets Key Permissions**: It sets the ownership and permissions of the generated OAuth2 keys to ensure they are secure and accessible by the web server.
    ```bash
    docker exec -w /var/www/html/public/legacy/Api/V8/OAuth2/ crm bash -c 'chown www-data:www-data private.key'
    docker exec -w /var/www/html/public/legacy/Api/V8/OAuth2/ crm bash -c 'chown www-data:www-data public.key'
    docker exec -w /var/www/html/public/legacy/Api/V8/OAuth2/ crm bash -c 'chmod 600 public.key'
    docker exec -w /var/www/html/public/legacy/Api/V8/OAuth2/ crm bash -c 'chmod 600 private.key'
    ```
